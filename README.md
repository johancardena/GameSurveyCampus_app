# 🎮 GameSurveyCampus_app

Aplicación móvil desarrollada con **Ionic + Angular + Capacitor**, que permite realizar encuestas sobre videojuegos, capturar ubicación GPS, tomar fotos con la cámara del dispositivo y almacenar la información en **Firebase Firestore**.

## Funcionalidades

-  Registro de encuestas sobre videojuegos
- Captura de ubicación en tiempo real (Geolocation)
-  Uso de cámara del dispositivo
-  Almacenamiento en Firebase Firestore
-  Aplicación híbrida Android (APK con Capacitor)
-  Integración con Firebase (Auth y Database)


## Tecnologías utilizadas

- Ionic Angular
- Angular Standalone Components
- Capacitor
- Firebase (Firestore)
- TypeScript
- HTML / SCSS
